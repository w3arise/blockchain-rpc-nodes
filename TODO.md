# TODO

- **Nitro release-body tag lookup:** Nitro release notes are inconsistent about which image they name. v3.12.0 names only `vX.Y.Z-<hash>-stripped`; v3.12.1 and v3.12.2 name the plain `vX.Y.Z-<hash>`. Without a suffix, `docker-tag-from-body` (`scripts/lib/auto-upgrade-yaml.py`) matches only the plain form, so a release whose notes name only `-stripped` makes CI fail for the Nitro rows (`arbitrum`, `plume`, `robinhood`, `robinhood-feed-relay`). Fix: accept the plain tag, and fall back to `-stripped` when the notes name only that.
- **Owner decision pending, auto-apply quiet skip:** `scripts/auto-apply-if-merged.sh` now skips a target quietly when its pin var is missing from `.env` and it has no containers. Before, that case was a DENY with exit 1 on every run. The skip exists so hosts with an older `robinhood/.env` (no `FEED_RELAY_IMAGE`) and no relay don't fail every cron run. It applies to every target. Keep it, or go back to the strict DENY and ask operators to add new pin vars to `.env` first.
